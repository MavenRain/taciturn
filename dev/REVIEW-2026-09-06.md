# Staged review, 2026-09-06

Scope: the staged Stage B changes at the start of this review.  All ten
confirmed findings below are fixed.  The review preserved the original
staged work and adds fixes without committing or publishing.

## CI findings, checked first

1) HIGH: `test/dune` registered only parser fixtures.  Adding a failing
   checker fixture left the old parser-only action green.  The test action
   and executable default now run the parser, CHECK and NEG legs, and Dune
   tracks all three fixture directories.
2) HIGH: `dev/strip-ocaml.awk` hid code after valid OCaml prose.  Both
   `(* "*)" *)` and `{| " |}` could hide a subsequent `assert false`.
   The scanner now tracks strings inside comments, quoted strings and
   character literals.  `dev/strip-ocaml-tests.sh` checks ten visible code
   lines, preserved line widths and rejection of unfinished prose.
3) MEDIUM: SB-G10 passed when `dev/strip-ocaml.awk` was missing.  The
   reproduced gate reported zero code hits despite a forbidden statement.
   It now requires successful file enumeration and stripping, nonempty
   input and the expected search exit status.

## Kernel and disclosure findings

4) HIGH: `Rules.spi_intro_sec` ignored a lambda's annotated domain, and
   `Conv.spine_step` trusted the application frame's domain.  A checked
   function with a forged Prop domain made `F (f 0)` convert to `F (f 1)`.
   Lambda domains now typecheck and convert to the expected domain;
   conversion uses the actual head's domain.  The rules fixtures reject
   the source exploit, and `test/kernel_review.ml` separately checks that
   natural arguments remain distinct while proof irrelevance still works.
5) HIGH: `Check.check_decl` allowed global replacement.  Declaring `p : P`,
   storing it in a definition, then redeclaring `p : Nat` invalidated the
   earlier definition's type.  Replacing a definition with a self-reference
   also checked.  Duplicate globals, including built-ins, now reject.
6) HIGH: `Global.check_signature` checked only extern arity.  A `verifyRaw`
   declaration could replace its public argument mark with `w`; an
   annotation or function alias then bypassed the syntactic call check.
   Linking now checks every binder mark against the disclosed signature.
   Both alias and annotation regression fixtures reject with Quantity.
7) HIGH: `Link.postulate` classified the unnormalized declaration type.
   `def Hidden : Type 0 := (w x : Nat) -> Nat` followed by
   `axiom hidden : Hidden` admitted an undisclosed witness-taking function.
   Postulate types now normalize before linking, and the binder walk peels
   annotations.  Plain aliases, annotated aliases and aliased codomains
   reject; a correctly declared extern type alias still checks.
8) HIGH: a ledger axiom name bypassed witness checks.  Declaring
   `axiom sound : (w x : Nat) -> Nat` allowed a public result from a witness
   without `prove`.  Ledger axioms now reject witness arguments, including
   arguments hidden behind type and function aliases.
9) MEDIUM: `Check.extern_point` inferred extern arguments instead of
   checking them against their domains.  Passing a valid lambda as the
   witness argument to `prove` failed with Cannot_infer.  The checker now
   uses the head's expected domain; the lambda regression checks.
10) MEDIUM: the `axioms` command omitted postulates outside the fixed
    ledger.  `axiom arbitrary : Nat` produced an empty report, and ledger
    rows omitted the actual declared type.  Every file axiom and extern
    now prints its checked type with any matching ledger description.
    `test/link_review.ml` covers both cases.  SB-G7 checks all five
    postulates in its existing fixture, once each.
